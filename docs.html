API reference

Two endpoints: upload a file, and revoke a key. Both are plain HTTPS — no SDK required. If you don't have a key yet, generate one here.

Authentication

Send your API key as a bearer token on every request:

Authorization: Bearer ls_live_your_key_here

Keys don't expire on their own, but you can revoke one any time from the Developers page.

Upload a file

POST https://fgetfjswkwyenfdpcxar.supabase.co/functions/v1/api-upload

Send a multipart/form-data body.

FieldRequiredDescription
fileYesThe file to upload. Up to 200MB.
expires_in_msNoMilliseconds until the link expires. Omit for a link that never expires.
public_listedNo"true" to show the file on Link Share's public gallery. Defaults to private.
curl -X POST https://fgetfjswkwyenfdpcxar.supabase.co/functions/v1/api-upload \
  -H "Authorization: Bearer ls_live_your_key_here" \
  -F "file=@/path/to/photo.jpg" \
  -F "expires_in_ms=604800000"
const form = new FormData();
form.append('file', fileInput.files[0]);
form.append('public_listed', 'true');

const res = await fetch('https://fgetfjswkwyenfdpcxar.supabase.co/functions/v1/api-upload', {
  method: 'POST',
  headers: { Authorization: 'Bearer ls_live_your_key_here' },
  body: form
});
const data = await res.json();
console.log(data.raw_url);
import requests

with open("photo.jpg", "rb") as f:
    res = requests.post(
        "https://fgetfjswkwyenfdpcxar.supabase.co/functions/v1/api-upload",
        headers={"Authorization": "Bearer ls_live_your_key_here"},
        files={"file": f},
    )
data = res.json()
print(data["raw_url"])

Response — 200 OK

{
  "slug": "8f2a91cd",
  "file_name": "photo.jpg",
  "mime_type": "image/jpeg",
  "category": "image",
  "size_bytes": 482113,
  "raw_url": "https://fgetfjswkwyenfdpcxar.supabase.co/storage/v1/object/public/linkshare/image/8f2a91cd-photo.jpg",
  "expires_at": "2026-09-22T16:04:00.000Z"
}

raw_url is a direct link — drop it straight into an <img>, <video>, or download link on your own site.

StatusMeaning
401Missing, invalid, or revoked API key.
400No file field, empty file, or file over 200MB.
500Upload or database error — safe to retry.

Revoke a key

POST https://fgetfjswkwyenfdpcxar.supabase.co/functions/v1/api-revoke
curl -X POST https://fgetfjswkwyenfdpcxar.supabase.co/functions/v1/api-revoke \
  -H "Content-Type: application/json" \
  -d '{"api_key":"ls_live_your_key_here"}'

Returns 200 with a confirmation message, or 404 if the key doesn't exist.

Limits

200MB per file. Uploads across the whole site (site + API combined) are capped at 20 per rolling 60 seconds — if you hit that, wait a moment and retry.
